# UERANSIM AMF Churn Test

This setup is for synthetic attach/detach overhead experiments:

- AMF stress comes from scaling many UERANSIM UEs up and down.
- UE mapper/control-plane monitoring stress comes from repeated registration and PDU session lifecycle events.
- No user-plane traffic is generated by this runner.

It intentionally does not model RF conditions.

## Prepare Subscribers

Generate and insert enough Open5GS subscribers for the largest UE wave:

```bash
./add-churn-subscribers.sh 100
```

The generated IMSIs start at:

```text
001010000100000
```

and alternate between:

- slice `1-000001`, DNN `internet`
- slice `1-000002`, DNN `streaming`

## Deploy gNB and Scalable UE StatefulSet

```bash
./deploy-ran-churn.sh 0
```

The UE StatefulSet starts at `0` replicas so you can begin from a clean baseline.

## Run Attach/Detach Churn

```bash
scripts/ueransim-churn/run-churn.sh --counts "10 25 50 100" --settle-seconds 90
```

## Cleanup

```bash
./remove-ran-churn.sh
```
